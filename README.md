# Launch Mission Tracker

世界中のロケット打ち上げスケジュールをリアルタイムのカウントダウンやシーケンスとともに追跡できる、Webベースのミッション管理・ダッシュボードアプリケーションです。

## 主な機能

- **打ち上げ一覧の自動/手動管理**: [The Space Devs (Launch Library 2)](https://thespacedevs.com/) のAPIを利用した最新の打ち上げスケジュール同期、およびローカルプリセットの切り替えに対応。
- **マルチロケット・シーケンス対応**: Falcon 9、Starship、JAXA (H3 / H-IIA)、標準ロケットなどのイベントシーケンス（T-/X- マイナスからのカウントダウン）を自動切替・表示。
- **リアルタイム・シミュレーションモード**: 実際の時刻ベースの進行に加え、カウントダウンを自由に進めたりテストできるシミュレーションモードを搭載。
- **カウントダウン制御**: カウントダウンの **HOLD（一時停止）** や **SCRUB（打ち上げ中止）**、カスタムイベントの編集に対応。
- **レスポンシブ・サイバーUI**: ダークテーマを基調とした、視認性の高いフューチャリスティックなUIデザイン（長いミッション名やカッコ書きのスマートな自動折り返しに対応）。

## 導入方法

1. リポジトリをクローンまたはダウンロードします。
2. アプリケーションのコードが含まれるHTMLファイル（例: `index.html`）を用意します。
3. 同階層にファビコン用の画像などを配置し、ブラウザでHTMLファイルを開くことでそのまま動作します（ローカルサーバーやGitHub Pages等でのホストにも対応）。

## 使い方

- **API同期**: ヘッダーの「API同期」ボタンをクリックすると、最新の打ち上げ予定データをリモートAPIから取得します。
- **ミッション選択**: 画面左側の「打ち上げ一覧」から確認したいミッションをクリックします。ロケットの種類に応じて自動的に専用のシーケンスが右側に読み込まれます。
- **シミュレーション**: 「シミュレーション切替」ボタンで、テスト用のカウントダウン進行に切り替えることができます。
- **シーケンスの編集**: 「シーケンス編集」ボタンから、秒数とイベント名のカスタムリストをJSONライクに編集可能です。
